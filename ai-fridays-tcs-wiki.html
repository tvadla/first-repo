01 Foundations

AI Foundations / Fundamentos de IA

🇬🇧 English

Artificial Intelligence (AI) is a branch of computer science dedicated to building systems that can perceive, reason, learn, and act. AI is not a single technology — it is an umbrella term that encompasses dozens of subfields, each with distinct methods and goals.

The Core Subfields of AI

Machine Learning (ML) — algorithms that learn patterns from data. Instead of explicit rules, the system discovers statistical regularities from examples. ML has three major paradigms:

  • Supervised Learning: Model learns from labeled examples (input → output pairs). Used for classification (spam detection, medical diagnosis) and regression (price prediction, demand forecasting).
  • Unsupervised Learning: Model finds hidden structure in unlabeled data. Used for clustering (customer segmentation), dimensionality reduction (PCA, t-SNE), and anomaly detection.
  • Reinforcement Learning (RL): Agent learns by interacting with an environment and receiving rewards/penalties. Used in robotics, game playing (AlphaGo), autonomous driving, and RLHF (training LLMs with human feedback).

Deep Learning (DL) — a subset of ML using artificial neural networks with many hidden layers. Deep learning excels at learning hierarchical representations: from pixels → edges → shapes → objects. This hierarchy makes it possible to handle complex, high-dimensional data like images, audio, and text.

Natural Language Processing (NLP) — teaching machines to understand, interpret, and generate human language. Modern NLP is dominated by Transformer-based models. Key tasks: text classification, named entity recognition (NER), machine translation, question answering, summarization, and dialogue systems.

Computer Vision (CV) — enabling machines to interpret visual data from images and videos. Key tasks: image classification, object detection (YOLO, Faster R-CNN), semantic segmentation (U-Net), pose estimation, and OCR (optical character recognition).

Generative AI — models that create new content: text (GPT, Claude), images (Stable Diffusion, DALL·E, Midjourney), audio (Bark, MusicGen), video (Sora, Runway), and code (Codex, Copilot). Generative AI uses architectures like Transformers (for language), Diffusion Models (for images), and GANs (generative adversarial networks).

🇲🇽 Español

La Inteligencia Artificial (IA) es una rama de la informática dedicada a construir sistemas que pueden percibir, razonar, aprender y actuar. La IA no es una sola tecnología — es un término paraguas que abarca docenas de subcampos, cada uno con métodos y objetivos distintos.

Los Subcampos Fundamentales de la IA

Aprendizaje Automático (ML) — algoritmos que aprenden patrones de datos. En vez de reglas explícitas, el sistema descubre regularidades estadísticas de ejemplos. ML tiene tres paradigmas principales:

  • Aprendizaje Supervisado: El modelo aprende de ejemplos etiquetados (entrada → salida). Usado para clasificación (detección de spam, diagnóstico médico) y regresión (predicción de precios, pronóstico de demanda).
  • Aprendizaje No Supervisado: El modelo encuentra estructura oculta en datos no etiquetados. Usado para clustering (segmentación de clientes), reducción de dimensionalidad (PCA, t-SNE) y detección de anomalías.
  • Aprendizaje por Refuerzo (RL): Un agente aprende interactuando con un entorno y recibiendo recompensas/penalizaciones. Usado en robótica, juegos (AlphaGo), conducción autónoma y RLHF (entrenamiento de LLMs con retroalimentación humana).

Aprendizaje Profundo (DL) — un subconjunto de ML usando redes neuronales artificiales con muchas capas ocultas. Sobresale en aprender representaciones jerárquicas: de píxeles → bordes → formas → objetos.

Procesamiento de Lenguaje Natural (NLP) — enseñar a las máquinas a comprender, interpretar y generar lenguaje humano. El NLP moderno está dominado por modelos basados en Transformers. Tareas clave: clasificación de texto, reconocimiento de entidades (NER), traducción automática, respuesta a preguntas, resumen y sistemas de diálogo.

Visión por Computadora (CV) — permitir que las máquinas interpreten datos visuales. Tareas clave: clasificación de imágenes, detección de objetos (YOLO), segmentación semántica (U-Net), estimación de pose y OCR.

IA Generativa — modelos que crean contenido nuevo: texto (GPT, Claude), imágenes (Stable Diffusion, DALL·E), audio (Bark, MusicGen), video (Sora, Runway) y código (Codex, Copilot). Usa arquitecturas como Transformers, Modelos de Difusión y GANs.

02 Deep Dive

How Neural Networks Work / Cómo Funcionan las Redes Neuronales

🇬🇧 English

A neural network is a mathematical function composed of interconnected layers of nodes (neurons). Each neuron receives inputs, multiplies them by weights, adds a bias, and passes the result through an activation function. The magic lies in how these simple operations, repeated across millions of neurons, can approximate incredibly complex functions.

🇲🇽 Español

Una red neuronal es una función matemática compuesta por capas interconectadas de nodos (neuronas). Cada neurona recibe entradas, las multiplica por pesos, agrega un sesgo, y pasa el resultado por una función de activación. La magia está en cómo estas operaciones simples, repetidas a través de millones de neuronas, pueden aproximar funciones increíblemente complejas.

2.2 The Training Process: Forward + Backpropagation

🇬🇧 English

Forward Propagation

Input data flows through the network layer by layer. Each layer applies: output = activation(weights · input + bias). The final layer produces a prediction. No learning happens here — it's just computation.

Loss Calculation

Compare the prediction to the actual label using a loss function. Cross-Entropy Loss for classification: L = -Σ y·log(ŷ). MSE for regression: L = (1/n)Σ(y - ŷ)². The loss is a single number measuring "how wrong" the model is.

Backpropagation

The algorithm calculates the gradient (partial derivative) of the loss with respect to every weight in the network, using the chain rule of calculus. This tells us: "how much does each weight contribute to the error?"

Weight Update (Gradient Descent)

Update each weight: w_new = w_old - learning_rate × gradient. The learning rate controls step size. Too large → overshooting. Too small → slow convergence. Modern optimizers (Adam, AdamW) adapt the learning rate per-parameter.

Repeat for Every Batch and Epoch

One full pass through the dataset = 1 epoch. Typically train for 3-100+ epochs. Each epoch processes data in mini-batches (32, 64, 128, 256 samples) for efficiency and gradient stability.

🇲🇽 Español

Propagación Hacia Adelante

Los datos de entrada fluyen por la red capa por capa. Cada capa aplica: salida = activación(pesos · entrada + sesgo). La capa final produce una predicción. No ocurre aprendizaje aquí — es solo cómputo.

Cálculo de Pérdida

Comparar la predicción con la etiqueta real usando una función de pérdida. Cross-Entropy para clasificación: L = -Σ y·log(ŷ). MSE para regresión: L = (1/n)Σ(y - ŷ)². La pérdida es un solo número que mide "qué tan equivocado" está el modelo.

Retropropagación

El algoritmo calcula el gradiente (derivada parcial) de la pérdida respecto a cada peso en la red, usando la regla de la cadena del cálculo. Esto nos dice: "¿cuánto contribuye cada peso al error?"

Actualización de Pesos (Descenso de Gradiente)

Actualizar cada peso: w_nuevo = w_anterior - tasa_aprendizaje × gradiente. La tasa de aprendizaje controla el tamaño del paso. Optimizadores modernos (Adam, AdamW) adaptan la tasa por parámetro.

Repetir para Cada Batch y Época

Un paso completo por el dataset = 1 época. Típicamente se entrena por 3-100+ épocas. Cada época procesa datos en mini-batches (32, 64, 128, 256 muestras).

2.4 The Transformer Architecture (Powers All Modern LLMs)

🇬🇧 English

The Transformer (Vaswani et al., 2017, "Attention Is All You Need") replaced RNNs/LSTMs as the dominant architecture for sequence processing. Its core innovation: Self-Attention.

Self-Attention Mechanism

For each token in a sequence, self-attention computes how much "attention" to pay to every other token. This creates contextual understanding — the word "bank" gets different representations in "river bank" vs "bank account".

The process: each token is projected into three vectors — Query (Q), Key (K), Value (V) — using learned weight matrices. Attention scores = softmax(QKᵀ/√d). The output is a weighted sum of the Value vectors.

Multi-Head Attention

Instead of one attention operation, Transformers use 8-128 parallel "heads", each learning different types of relationships (syntax, semantics, coreference, etc.). Outputs are concatenated and linearly projected.

Key Components:

  • Positional Encoding: Sine/cosine or learned embeddings added to tokens to encode position (Transformers have no inherent notion of order).
  • Feed-Forward Network: Two linear layers with activation between them, applied to each position independently.
  • Layer Normalization: Stabilizes training by normalizing activations within each layer.
  • Residual Connections: Skip connections that add the input of a sublayer to its output, enabling deep networks to train effectively.
🇲🇽 Español

El Transformer (Vaswani et al., 2017, "Attention Is All You Need") reemplazó a las RNNs/LSTMs como la arquitectura dominante. Su innovación central: Auto-Atención (Self-Attention).

Mecanismo de Auto-Atención

Para cada token en una secuencia, la auto-atención calcula cuánta "atención" prestar a cada otro token. Esto crea comprensión contextual — la palabra "banco" obtiene representaciones diferentes en "banco del río" vs "cuenta de banco".

El proceso: cada token se proyecta en tres vectores — Query (Q), Key (K), Value (V) — usando matrices de pesos aprendidas. Scores de atención = softmax(QKᵀ/√d). La salida es una suma ponderada de los vectores Value.

Atención Multi-Cabeza

En lugar de una sola operación de atención, los Transformers usan 8-128 "cabezas" paralelas, cada una aprendiendo diferentes tipos de relaciones (sintaxis, semántica, correferencia, etc.).

Componentes Clave:

  • Codificación Posicional: Embeddings seno/coseno o aprendidos añadidos a los tokens para codificar posición.
  • Red Feed-Forward: Dos capas lineales con activación, aplicadas a cada posición independientemente.
  • Normalización de Capa: Estabiliza el entrenamiento normalizando activaciones dentro de cada capa.
  • Conexiones Residuales: Conexiones de salto que suman la entrada de una subcapa a su salida.
03 Core Concept

What Are Embeddings / Qué son los Embeddings

🇬🇧 English

An embedding is a learned numerical representation (vector) of data in a continuous, high-dimensional space. It converts discrete, unstructured data — words, sentences, images, audio — into dense arrays of floating-point numbers where semantically similar items are geometrically close.

Why Embeddings Matter

Computers can't understand text or images directly — they need numbers. Embeddings are the bridge. But unlike one-hot encoding (which creates sparse, meaningless vectors), embeddings capture meaning:

  • "king" - "man" + "woman" ≈ "queen" — arithmetic on word vectors captures analogies.
  • cosine_similarity("happy", "joyful") ≈ 0.92 — synonyms are close in embedding space.
  • cosine_similarity("happy", "sad") ≈ 0.35 — antonyms are distant.
  • cosine_similarity("cat", "quantum physics") ≈ 0.05 — unrelated concepts are very far apart.

Types of Embeddings

  • Word Embeddings (Word2Vec, GloVe, FastText): Each word → single vector. "dog" always has the same embedding regardless of context. Limited but fast.
  • Contextual Embeddings (BERT, GPT): Same word → different vectors depending on context. "bank" in "river bank" ≠ "bank" in "bank account". Far more powerful.
  • Sentence/Document Embeddings (text-embedding-3, BGE, E5): Entire text passages → single vector. Essential for RAG, semantic search, and clustering.
  • Image Embeddings (CLIP, DINOv2): Images → vectors. Enables cross-modal search: find images using text queries.
  • Multimodal Embeddings (CLIP, ImageBind): Text and images share the same vector space. "a photo of a cat" and an actual cat image have similar embeddings.
🇲🇽 Español

Un embedding es una representación numérica aprendida (vector) de datos en un espacio continuo de alta dimensión. Convierte datos discretos y no estructurados — palabras, oraciones, imágenes, audio — en arrays densos de números de punto flotante donde elementos semánticamente similares están geométricamente cerca.

Por qué Importan los Embeddings

Las computadoras no pueden entender texto o imágenes directamente — necesitan números. Los embeddings son el puente. A diferencia de one-hot encoding (que crea vectores dispersos sin significado), los embeddings capturan significado:

  • "rey" - "hombre" + "mujer" ≈ "reina" — la aritmética de vectores captura analogías.
  • cosine_similarity("feliz", "contento") ≈ 0.92 — sinónimos están cerca en el espacio de embeddings.
  • cosine_similarity("feliz", "triste") ≈ 0.35 — antónimos están distantes.

Tipos de Embeddings

  • Embeddings de Palabras (Word2Vec, GloVe, FastText): Cada palabra → un solo vector. Limitados pero rápidos.
  • Embeddings Contextuales (BERT, GPT): La misma palabra → diferentes vectores según contexto. Mucho más poderosos.
  • Embeddings de Oración/Documento (text-embedding-3, BGE, E5): Pasajes completos de texto → un solo vector. Esenciales para RAG y búsqueda semántica.
  • Embeddings de Imagen (CLIP, DINOv2): Imágenes → vectores. Permite búsqueda cross-modal.
  • Embeddings Multimodales (CLIP, ImageBind): Texto e imágenes comparten el mismo espacio vectorial.

3.1 Embedding Code Examples

Python — Generate Embeddings Locally (Free, No Server)
from sentence_transformers import SentenceTransformer
import numpy as np

# Download and load model locally (runs on CPU, no API needed)
model = SentenceTransformer('all-MiniLM-L6-v2')  # 384 dimensions

texts = [
    "The cat sat on the mat",
    "A kitten was resting on the rug",
    "Quantum physics describes subatomic particles"
]

# Generate embeddings
vectors = model.encode(texts)   # Shape: (3, 384)

# Calculate cosine similarity
def cosine_sim(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

print(f"Cat vs Kitten:   {cosine_sim(vectors[0], vectors[1]):.4f}")   # ~0.89 HIGH
print(f"Cat vs Quantum:  {cosine_sim(vectors[0], vectors[2]):.4f}")   # ~0.12 LOW

05 Architecture

RAG — Retrieval-Augmented Generation

🇬🇧 English

RAG enhances LLM responses by retrieving relevant documents from an external knowledge base before generating an answer. The model answers based on real evidence — not just its training data.

Why RAG? LLMs hallucinate, have knowledge cutoff dates, and lack access to private data. RAG solves all three: reduces hallucinations, provides up-to-date answers, and works with proprietary documents — without the cost of fine-tuning.

🇲🇽 Español

RAG mejora las respuestas del LLM recuperando documentos relevantes de una base de conocimiento externa antes de generar una respuesta. El modelo responde basándose en evidencia real — no solo en sus datos de entrenamiento.

¿Por qué RAG? Los LLMs alucinan, tienen fechas de corte de conocimiento y carecen de acceso a datos privados. RAG resuelve los tres problemas: reduce alucinaciones, provee respuestas actualizadas y funciona con documentos propietarios — sin el costo de fine-tuning.

import requests, json, os
from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import HuggingFaceEmbeddings
from dotenv import load_dotenv

load_dotenv()
SERVER = os.getenv("MODEL_SERVER_URL")   # Your server URL
MODEL = os.getenv("MODEL_NAME")          # Your model name

# ── STEP 1: Load Documents ──
loader = PyPDFLoader("company_handbook.pdf")
documents = loader.load()
print(f"Loaded {len(documents)} pages")

# ── STEP 2: Chunk Documents ──
splitter = RecursiveCharacterTextSplitter(
    chunk_size=800, chunk_overlap=150,
    separators=["\n\n", "\n", ". ", " ", ""]
)
chunks = splitter.split_documents(documents)
print(f"Created {len(chunks)} chunks")

# ── STEP 3: Create Embeddings + Vector Store (local, free) ──
embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = Chroma.from_documents(
    documents=chunks, embedding=embeddings,
    persist_directory="./chroma_db", collection_name="company_docs"
)

# ── STEP 4: Build Retriever ──
retriever = vectorstore.as_retriever(search_type="mmr", search_kwargs={"k": 5})

# ── STEP 5: RAG Query Function (pure Python + requests) ──
def rag_query(question: str):
    """Retrieve context + call model server with pure Python"""
    # Retrieve relevant document chunks
    docs = retriever.invoke(question)
    context = "\n\n".join([d.page_content for d in docs])

    # Build augmented prompt with context
    prompt = f"""Answer based ONLY on this context. If unsure, say so.

Context:
{context}

Question: {question}
Answer:"""

    # Call YOUR model server with requests
    resp = requests.post(
        f"{SERVER}/v1/chat/completions",
        headers={"Content-Type": "application/json"},
        json={
            "model": MODEL,
            "messages": [
                {"role": "system", "content": "You are a helpful TCS assistant. Cite your sources."},
                {"role": "user", "content": prompt}
            ],
            "temperature": 0
        }
    )
    resp.raise_for_status()
    answer = resp.json()["choices"][0]["message"]["content"]
    sources = [{"source": d.metadata.get("source","?"), "page": d.metadata.get("page","?")} for d in docs]
    return answer, sources

answer, sources = rag_query("What is the remote work policy?")
print(answer)
for s in sources:
    print(f"  📄 {s['source']} — Page {s['page']}")

UX/UI for AI Applications

🇬🇧 English

Designing interfaces for AI-powered applications requires rethinking traditional UX patterns. AI introduces uncertainty, latency, and non-determinism — the same input might produce different outputs. Great AI UX manages expectations, builds trust, and keeps humans in control.

Core UX Principles for AI

  • Transparency: Always indicate when AI is generating content. Show loading states, confidence levels, and source attribution.
  • Progressive Disclosure: Show the answer first, then allow users to drill into sources, reasoning, and alternatives.
  • Error Recovery: AI will be wrong. Provide easy "regenerate", "edit", and "thumbs down" mechanisms.
  • Streaming Output: Stream tokens as they're generated (like ChatGPT) rather than waiting for the full response. This reduces perceived latency dramatically.
  • Guardrails & Constraints: Use dropdowns, toggles, and structured inputs to constrain AI behavior. Free-form text boxes are powerful but unpredictable.
  • Feedback Loops: Collect user feedback (thumbs up/down, corrections) to improve the system over time.

UI Patterns for AI Chatbots (Streamlit / Gradio)

  • st.chat_message: Streamlit provides built-in chat bubbles with distinct user/assistant styles.
  • st.write_stream: Native streaming — tokens appear as they're generated.

# services/rag_service.py
import requests
import json
from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import HuggingFaceEmbeddings
import tempfile, os
from dotenv import load_dotenv

load_dotenv()

class RAGService:
    def __init__(self):
        # Connection to YOUR model server
        self.server_url = os.getenv("MODEL_SERVER_URL")
        self.model_name = os.getenv("MODEL_NAME")
        self.api_key = os.getenv("API_KEY", "")
        self.headers = {"Content-Type": "application/json"}
        if self.api_key:
            self.headers["Authorization"] = f"Bearer {self.api_key}"

        self.embeddings = HuggingFaceEmbeddings(
            model_name="all-MiniLM-L6-v2"     # Free, runs locally on CPU!
        )
        self.vectorstore = Chroma(
            persist_directory="./data/chroma_db",
            embedding_function=self.embeddings,
            collection_name="tcs_docs"
        )
        self.splitter = RecursiveCharacterTextSplitter(
            chunk_size=800,
            chunk_overlap=150,
            separators=["\n\n", "\n", ". ", " ", ""]
        )

    def ingest_files(self, uploaded_files):
        """Process uploaded PDFs: chunk + embed + store"""
        all_chunks = []
        for file in uploaded_files:
            # Save to temp file (Streamlit uploads are in memory)
            with tempfile.NamedTemporaryFile(delete=False, suffix=".pdf") as tmp:
                tmp.write(file.read())
                tmp_path = tmp.name

            # Load and chunk
            loader = PyPDFLoader(tmp_path)
            pages = loader.load()
            chunks = self.splitter.split_documents(pages)
            all_chunks.extend(chunks)
            os.unlink(tmp_path)

        # Add to vector store
        self.vectorstore.add_documents(all_chunks)
        return len(all_chunks)

    def retrieve(self, query: str, k: int = 5):
        """Semantic search in vector store"""
        return self.vectorstore.similarity_search(query, k=k)

    def get_chunk_count(self):
        """Count total chunks in the database"""
        try:
            return self.vectorstore._collection.count()
        except:
            return 0

    def stream_response(self, query: str, context: str, temperature: float = 0.3):
        """Stream response from model server with pure Python"""
        prompt = f"""Answer based ONLY on this context. If the context doesn't
contain the answer, say "I don't have enough information."

Context:
{context}

Question: {query}

Answer clearly and professionally:"""

        payload = {
            "model": self.model_name,
            "messages": [
                {"role": "system", "content": "You are a helpful TCS AI assistant."},
                {"role": "user", "content": prompt}
            ],
            "temperature": temperature,
            "stream": True
        }
        response = requests.post(
            f"{self.server_url}/v1/chat/completions",
            headers=self.headers, json=payload, stream=True
        )
        for line in response.iter_lines():
            if line:
                line = line.decode("utf-8")
                if line.startswith("data: ") and line != "data: [DONE]":
                    chunk = json.loads(line[6:])
                    content = chunk["choices"][0].get("delta", {}).get("content", "")
                    if content:
                        yield content

# ai_client.py — Call your model server with pure Python
import requests, json, os
from dotenv import load_dotenv

load_dotenv()

SERVER = os.getenv("MODEL_SERVER_URL", "http://localhost:8000")
MODEL = os.getenv("MODEL_NAME", "default-model")
API_KEY = os.getenv("API_KEY", "")
HEADERS = {"Content-Type": "application/json"}
if API_KEY:
    HEADERS["Authorization"] = f"Bearer {API_KEY}"

def ask_model(prompt, system="You are a helpful assistant.", temperature=0.3):
    """Send prompt to model server, return text response"""
    try:
        resp = requests.post(
            f"{SERVER}/v1/chat/completions",
            headers=HEADERS,
            json={
                "model": MODEL,
                "messages": [
                    {"role": "system", "content": system},
                    {"role": "user", "content": prompt}
                ],
                "temperature": temperature
            },
            timeout=60
        )
        resp.raise_for_status()
        return resp.json()["choices"][0]["message"]["content"]
    except requests.exceptions.ConnectionError:
        return f"❌ Cannot connect to server: {SERVER}"
    except Exception as e:
        return f"❌ Error: {str(e)}"

def ask_model_stream(prompt, system="You are a helpful assistant."):
    """Stream response token by token"""
    try:
        resp = requests.post(
            f"{SERVER}/v1/chat/completions",
            headers=HEADERS,
            json={"model": MODEL, "messages": [
                {"role": "system", "content": system},
                {"role": "user", "content": prompt}
            ], "stream": True},
            stream=True, timeout=60
        )
        for line in resp.iter_lines():
            if line:
                line = line.decode("utf-8")
                if line.startswith("data: ") and line != "data: [DONE]":
                    chunk = json.loads(line[6:])
                    c = chunk["choices"][0].get("delta",{}).get("content","")
                    if c: yield c
    except Exception as e:
        yield f"❌ Error: {str(e)}"

# Quick test
if __name__ == "__main__":
    print(ask_model("Say hello in Spanish"))

-- Semantic search: find similar documents
