User Story
Backup & Recovery Readiness Scorecard Platform
As an infrastructure resilience lead, I want a backup readiness tool that classifies systems into Ready, At-Risk, and Critical based on backup freshness and success rate, so that I can reduce recovery failures without advanced analytics.

Objective
Build a rule-based backup readiness scoring module and dashboard.

Readiness Logic

Ready: Last backup within RPO window + success rate above threshold
At-Risk: Backup within window but low success rate or missing periodic test
Critical: RPO breached or repeated failures
Key Features

Rule Engine: Define RPO thresholds and success-rate thresholds
Manual Data Entry / Upload: System, last backup time, success rate, test date, owner
Automatic Classification: Ready/At-Risk/Critical
Dashboard: Readiness by system tier, owner; filters + summary totals
Export Option: CSV/PDF remediation list for resilience reviews
